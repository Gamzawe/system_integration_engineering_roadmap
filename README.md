# 20-Week KSA/GCC Extraction Roadmap

Welcome to the **Interactive 20-Week KSA/GCC Extraction Roadmap**. This repository holds a focused sprint roadmap mapped into a fully interactive flowchart built from scratch using purely vanilla HTML, CSS, and JS.

**Philosophy:** Germany is the destination. KSA/GCC is the bridge. C# is the vehicle. Money is the fuel.

**Target:** C#/.NET Integration Engineer — Biometric, Kiosk, Identity & Edge Systems — KSA → Germany via Blue Card experience route.

---

## 🎨 Features & Functionality

Open `index.html` in your browser to experience the roadmap engine:

- **Interactive Flowchart Engine:** Custom SVG rendering system in vanilla JavaScript (`script.js`). Pixel-perfect pathways between nodes.
- **Section Collapsing:** Click `Phase` or `Week` blocks to collapse/expand. Auto-recalculates layout.
- **State Persistence (Local Storage):** Right-click any node → mark as **Done**, **In Progress**, or **Skip**. State retained across refreshes.
- **Data Detail Drawers:** Left-click any `Week` or `Day` block for full task definitions — Morning (C#) and Evening (Anki) sessions.
- **Thematic Styling:** Modern dark mode theme with CSS design tokens.

## 📚 Sprint Structure

The sprint comprises 6 phases:

0. **Phase 0 (Week 0): Pre-Flight** — Repo creation, ANABIN documentation, KSA job market mapping, tracking spreadsheet, Anki setup.
1. **Phase 1 (Weeks 1–5): Foundation Repair** — OOP, DI, testing, async/await, resilience, native interop, gRPC, minimal React dashboard.
2. **Phase 2 (Weeks 6–10): Cloud & Distribution** — Docker, CI/CD, Azure IoT Hub, messaging, EF Core, SOAP legacy, MQTT/OPC UA/Modbus, security, fleet simulation.
3. **Phase 3 (Weeks 11–13): Documentation & Proof** — C4 diagrams, ADRs, demo video, LinkedIn/XING profiles, CV EN+AR, test applications.
4. **Phase 4 (Weeks 14–20): KSA/GCC Market Entry** — Outreach waves, recruiter engagement, interview prep, sustained applications, offer negotiation.
5. **Phase 5 (Month 6–27): Post-Sprint** — Extended campaign, KSA experience building, German B1, Blue Card experience route to Germany.

## 🚀 Getting Started

No dependencies, no `npm install`, no build steps.

1. Clone or download this repository.
2. Double-click `index.html` to open in your browser.
3. **Left Click** nodes to peek at detailed learning tasks.
4. **Click Phase/Week nodes** to collapse or expand branches.
5. **Right Click** to mark tracking states.

If you modify `roadmap.txt`, regenerate `index.html`:
